Student Performance Predictor (Machine Learning)

Overview
This project predicts student exam scores using machine learning based on study hours, sleep, and previous academic performance.

Model Used
Linear Regression (Supervised Learning)

Tech Stack
- Python
- Pandas
- Scikit-learn
- Matplotlib

Features
- Data preprocessing
- Train-test split
- Model training and prediction
- Model evaluation using Mean Absolute Error
- Visualization of actual vs predicted results

Output
The model predicts student scores with low error and visualizes performance using scatter plots.

Future Improvements
- Use real-world datasets
- Try advanced models like Random Forest
- Improve feature engineering
